# Color Vocab Project

A Spanish vocabulary page for learning colors.

## Colors

- Rojo (red)
- Azul (blue)
- Anaranjado (orange)
- Verde (green)
- Amarillo (yellow)

Each color name is styled with its matching CSS color and shown next to a color image.

## Structure

- `index.html` — the vocabulary page
- `style.css` — color styling for each heading
- `assets/images/*.png` — the color images

## Viewing

Open `index.html` in any web browser.
